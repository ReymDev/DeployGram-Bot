# Changelog

Все значимые изменения в проекте DeployGram документируются в этом файле.

## [1.1.0] - 2024-06-22

### Исправлено 🐛

- **Критическая ошибка запуска контейнеров**: Исправлена проблема, из-за которой Docker не мог найти файлы проекта при запуске (`can't open file '/app/main.py': [Errno 2] No such file or directory`)
  - В `agent/main.py` исправлен путь к директории проекта при создании контейнера
  - Теперь используется метод `_get_project_dir()` для получения правильного пути `/app/data/projects/{project_id}`
  - Ранее использовался несуществующий путь `/data/projects/{project_id}`

### Добавлено ✨

- **Расширенное логирование**:
  - `agent/main.py` → логи при загрузке и распаковке проектов (список файлов)
  - `agent/main.py` → логи при создании контейнеров (параметры и пути)
  - `services/docker_manager.py` → логи монтирования volume и команд запуска
  
- **Документация**:
  - `BUGFIX_ENTRY_POINT.md` - техническое описание исправления ошибки
  - `DEPLOYMENT_GUIDE.md` - руководство по развертыванию обновлений
  - `docs/PROJECT_STRUCTURE_GUIDE.md` - подробное руководство по структуре проектов для пользователей
  - `CHANGELOG.md` - история изменений

### Улучшено 🚀

- Улучшена диагностика проблем с запуском проектов
- Добавлено отображение списка доступных файлов при ошибках
- Упрощена отладка проблем с путями через детальные логи

## [1.0.0] - 2024 (Initial Release)

### Добавлено ✨

#### Основной функционал
- Telegram-бот для хостинга Python-проектов в Docker
- Загрузка проектов через ZIP архив или GitHub
- Автоматический поиск entry point (main.py, bot.py, run.py, app.py)
- Поддержка Python 3.10, 3.11, 3.12
- Изоляция контейнеров (CPU, RAM, Disk лимиты)

#### Мониторинг и управление
- Мониторинг в реальном времени (CPU, RAM, Disk)
- Просмотр логов контейнеров через бота
- Запуск/остановка/перезапуск проектов
- Система уведомлений (остановки, ошибки, высокая нагрузка)

#### Работа с файлами
- Файловый менеджер с inline-навигацией
- Мобильный редактор кода
- Создание/удаление файлов и папок
- Система секретов (ENV переменные)

#### Версионирование и бэкапы
- Система версий с возможностью отката
- Автоматические бэкапы (Premium)
- Ручные бэкапы
- Восстановление из бэкапа

#### Совместная работа
- Совладельцы проектов с ролями (Owner, Developer)
- Разграничение прав доступа

#### Монетизация
- Тарифы: Free и Premium
- Free: 1 проект, 256MB RAM, 0.3 CPU, 100MB Disk
- Premium: до 5 проектов, 1024MB RAM, 1.0 CPU, 500MB Disk
- Система подписок (1 неделя - 12 месяцев)
- Промокоды
- Реферальная система

#### Админ-панель
- Статистика пользователей и проектов
- Управление промокодами
- Массовые рассылки
- Управление фото
- Блокировка пользователей

#### Инфраструктура
- VPS Agent для удалённых серверов
- Мультисерверность
- Выбор локации сервера
- Рейтинг серверов по ping и нагрузке

#### Архитектура
- Repository Pattern для работы с БД
- Service Layer для бизнес-логики
- Middleware: Database, Auth, RateLimit
- FSM для управления состояниями
- APScheduler для фоновых задач

#### Технологии
- Python 3.12
- aiogram 3.x (Telegram Bot API)
- SQLAlchemy 2.x (async ORM)
- Alembic (миграции БД)
- Redis (кэширование, rate limiting)
- Docker SDK (управление контейнерами)
- aiohttp (HTTP API для Agent)
- APScheduler (планировщик задач)
- Pydantic Settings (конфигурация)

## Формат

Changelog следует принципам [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и использует [Semantic Versioning](https://semver.org/lang/ru/).

### Типы изменений:
- **Добавлено** ✨ - новый функционал
- **Изменено** 🔄 - изменения в существующем функционале
- **Устарело** ⚠️ - функции, которые скоро будут удалены
- **Удалено** 🗑️ - удалённый функционал
- **Исправлено** 🐛 - исправления багов
- **Безопасность** 🔒 - исправления уязвимостей
