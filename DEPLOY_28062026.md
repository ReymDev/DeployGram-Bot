# Инструкция по деплою изменений от 28.06.2026

## Что нужно сделать на сервере

### 1. Подключиться к серверу
```bash
ssh root@94.183.254.95
```

### 2. Перейти в директорию проекта
```bash
cd ~/DeployGram-Bot
```

### 3. Проверить текущую версию
```bash
git log -1 --oneline
# Должен показать: 0861581 fix: agent and services now read files from container using docker exec
```

### 4. Обновить код
```bash
git pull origin main
```

Должны подтянуться 2 новых коммита:
- `93a5f38` - feat: add coowner permissions checks and notification system
- `45f0193` - feat: show coowned projects with tag in project list

### 5. Проверить что код обновился
```bash
git log -3 --oneline
```

Должно показать:
```
45f0193 (HEAD -> main, origin/main) feat: show coowned projects with tag in project list
93a5f38 feat: add coowner permissions checks and notification system
0861581 fix: agent and services now read files from container using docker exec
```

### 6. Перезапустить бота
```bash
cd docker
docker compose -p mainbot restart bot
```

### 7. Проверить логи
```bash
docker compose -p mainbot logs -f bot
```

Нажмите `Ctrl+C` чтобы выйти из просмотра логов.

### 8. Проверить что бот работает
В логах должны быть строки:
```
Scheduler started
DeployGram bot starting...
```

## Что изменилось

### ✅ Проверки разрешений совладельцев
- Теперь совладельцы могут иметь ограниченные права
- Проверяются разрешения: запуск/остановка, логи, файлы, зависимости, настройки

### ✅ Система уведомлений
- Автоматическая проверка нагрузки CPU/RAM каждые 10 минут
- Уведомления при превышении порогов (CPU > 80%, RAM > 400MB)
- Настройки уведомлений в профиле пользователя

### ✅ Отображение проектов совладельцев
- Совладельцы видят проекты с иконкой 👥
- Список проектов показывает все доступные проекты (владелец + совладелец)

## Тестирование

### 1. Проверка отображения совладельцев
```
1. Создайте проект от пользователя A
2. Добавьте пользователя B как совладельца
3. Зайдите от пользователя B в бот
4. Откройте "Мои проекты"
5. Проект должен отображаться с иконкой 👥
```

### 2. Проверка разрешений
```
1. У проекта, где вы совладелец
2. Настройте разрешения (например, только просмотр логов)
3. Попробуйте запустить проект - должно показать "⛔ У вас нет прав"
4. Попробуйте посмотреть логи - должно работать
```

### 3. Проверка уведомлений
```
1. Откройте "Профиль" → "⚙️ Настройки" → "🔔 Уведомления"
2. Включите нужные типы уведомлений
3. Запустите проект с высокой нагрузкой
4. Через 10 минут должно прийти уведомление о высокой нагрузке
```
