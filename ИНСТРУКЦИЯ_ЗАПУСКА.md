# 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ DeployGram

## 📋 Структура проекта
- **DeployGram-Bot** - Главный Telegram бот (порт 8080)
- **DeployGram-locate** - VPS Agent для локации (порт 8081)

---

## ⚠️ ВАЖНО: Используй project names чтобы избежать конфликтов!

---

## 🔵 ГЛАВНЫЙ БОТ (DeployGram-Bot)

### Остановка:
```bash
cd ~/DeployGram-Bot/docker
docker compose -p mainbot down
```

### Запуск:
```bash
cd ~/DeployGram-Bot/docker
git pull
docker compose -p mainbot up -d
```

### Проверка:
```bash
docker ps --filter "name=mainbot"
```

**Контейнеры:**
- `mainbot-bot-1` - Telegram бот
- `mainbot-agent-1` - Агент (порт 8080)
- `mainbot-redis-1` - Redis (порт 6379)

### Логи:
```bash
docker logs mainbot-bot-1 -f
docker logs mainbot-agent-1 -f
```

## ✅ ПРОВЕРКА РАБОТОСПОСОБНОСТИ

### Проверить все контейнеры:
```bash
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

**Должно быть:**
```
NAMES             STATUS              PORTS
mainbot-bot-1     Up X minutes        
mainbot-agent-1   Up X minutes        0.0.0.0:8080->8080/tcp
mainbot-redis-1   Up X minutes        0.0.0.0:6379->6379/tcp
locate-agent-1    Up X minutes        0.0.0.0:8081->8080/tcp
```

### Проверить health:
```bash
# Главный агент
curl -s http://localhost:8080/health

# Locate агент
curl -s http://localhost:8081/health
```

## 🐛 TROUBLESHOOTING

### ❌ Ошибка "port is already allocated"
```bash
# Найти процесс на порту
netstat -tulpn | grep :8080
netstat -tulpn | grep :8081

# Остановить все контейнеры без project name
docker stop $(docker ps -q --filter "name=docker-")
docker rm $(docker ps -aq --filter "name=docker-")

# Потом запускать с project names
```

### ❌ Ошибка "no configuration file provided"
**Проблема:** Не в папке docker/

**Решение:**
```bash
cd ~/DeployGram-Bot/docker        # для главного бота
cd ~/DeployGram-locate/docker     # для locate
```

### ❌ Контейнеры с именами docker-* вместо mainbot-*/locate-*
**Проблема:** Запустил без -p flag

**Решение:**
```bash
# Останови неправильные
docker compose down

# Запусти правильно
docker compose -p mainbot up -d   # или -p locate
```

## 🎯 ТЕКУЩАЯ КОНФИГУРАЦИЯ

**Paths:**
- Host: `/var/lib/deploygram/data/`
- Bot container: `/app/data/`
- Project container: `/app/` (mounted from host)

**Ports:**
- 8080 - Главный агент
- 8081 - Locate агент
- 6379 - Redis

**Проекты хранятся:**
- Host: `/var/lib/deploygram/data/projects/{id}/`
- Внутри проекта: `/app/`

## ⚡ САМОЕ ГЛАВНОЕ

**ВСЕГДА используй `-p` флаг при работе с docker compose:**

```bash
# ✅ ПРАВИЛЬНО
docker compose -p mainbot up -d
docker compose -p locate up -d

# ❌ НЕПРАВИЛЬНО (создаст конфликты)
docker compose up -d
```

**Это гарантирует уникальные имена контейнеров и избегает конфликтов портов!**
