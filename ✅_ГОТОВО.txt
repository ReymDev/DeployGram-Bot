🔧 РЕАЛИЗОВАННОЕ РЕШЕНИЕ
═══════════════════════════════════════════════════════════════

1️⃣ BIND MOUNT CONFIGURATION
   ├─ Создана директория на хосте: /var/lib/deploygram/data/
   ├─ Скопированы файлы из контейнера бота
   └─ Настроен bind mount в docker-compose.yml:
      volumes:
        - /var/lib/deploygram/data:/app/data

2️⃣ ИСПРАВЛЕН КОД В agent/main.py (ОБА ПРОЕКТА)
   ├─ DeployGram-Bot: ~/DeployGram-Bot/agent/main.py
   └─ DeployGram-locate: ~/DeployGram-locate/agent/main.py
   
   Метод _get_project_dir() теперь возвращает:
   ├─ Создаёт: /app/data/projects/{id} (внутренний путь)
   └─ Возвращает: /var/lib/deploygram/data/projects/{id} (путь хоста)

3️⃣ DOCKER COMPOSE PROJECT NAMES (избежание конфликтов)
   ├─ Main Bot: docker compose -p mainbot up -d
   │  └─ Контейнеры: mainbot-agent-1, mainbot-bot-1, mainbot-redis-1
   └─ Locate Agent: docker compose -p locate up -d
      └─ Контейнер: locate-agent-1

FILE: agent/main.py (оба проекта)

def _get_project_dir(self, project_id: str) -> str:
    """
    Возвращает путь к директории проекта.
    ВАЖНО: Возвращает путь на ХОСТЕ для монтирования в Docker,
    но создаёт директорию по внутреннему пути контейнера.
    """
    # Внутренний путь контейнера для создания директории
    internal_path = f"/app/data/projects/{project_id}"
    os.makedirs(internal_path, exist_ok=True)
    
    # Путь на хосте для монтирования в проектные контейнеры
    # Bind mount: /var/lib/deploygram/data:/app/data
    host_path = f"/var/lib/deploygram/data/projects/{project_id}"
    return host_path
─────────────────────────────────────────────────────────────

FILE: docker/docker-compose.yml (оба проекта)
─────────────────────────────────────────────────────────────
services:
  bot/agent:
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - /var/lib/deploygram/data:/app/data  ← BIND MOUNT
