# Изменения от 27.06.2026

## Исправленные проблемы

### ✅ 1. Реферальная система
**Проблема:** Приглашенные пользователи не засчитывались (показывало "приглашено 0")

**Исправление:**
- Исправлен метод `process_referral` в `services/referral.py`
- Теперь правильно конвертирует Telegram ID в внутренние ID пользователей
- Добавлена проверка существования пользователей перед созданием реферальной связи

**Файлы:** `services/referral.py`

---

### ✅ 2. Отображение зависимостей из requirements.txt
**Проблема:** Зависимости из requirements.txt не отображались в интерфейсе

**Исправление:**
- Обновлен хендлер `bot_libs` в `bot/handlers/user/bot_manage.py`
- Теперь читает и отображает зависимости из requirements.txt
- Показывает установленные пакеты с версиями в формате кнопок (например "aiogram==3.13.1")

**Файлы:** `bot/handlers/user/bot_manage.py`

---

### ✅ 3. Система разрешений для совладельцев
**Проблема:** Все совладельцы получали роль "developer" автоматически без возможности настройки

**Исправление:**
- Добавлены поля разрешений в модель `CoOwner`:
  - `can_start_stop` - запуск/остановка проекта
  - `can_view_logs` - просмотр логов
  - `can_edit_files` - редактирование файлов
  - `can_manage_deps` - управление зависимостями
  - `can_view_settings` - просмотр настроек
- Добавлен UI для настройки разрешений:
  - Кнопка редактирования в списке совладельцев
  - Переключатели для каждого разрешения
- Добавлены новые хендлеры:
  - `coowner_edit` - редактирование совладельца
  - `coowner_toggle_permission` - переключение разрешения

**Файлы:** 
- `models/coowner.py` - добавлены поля
- `bot/keyboards/user.py` - добавлена клавиатура `get_coowner_permissions_keyboard`
- `bot/handlers/user/coowners.py` - добавлены хендлеры
- `bot/texts.py` - добавлены тексты
- `db/migrations/versions/20260627_add_coowner_permissions.py` - миграция БД

---

### ✅ 4. Уведомления
**Проблема:** 
1. Уведомления вообще не приходили
2. Ошибка "проект не найден" при нажатии "назад" в настройках уведомлений

**Исправление:**
- Добавлена функция `get_settings_keyboard` в `bot/keyboards/user.py`
- Исправлен callback "назад" - теперь ведет на `profile` вместо несуществующего callback
- Добавлены иконки 🔔/🔕 для включенных/выключенных уведомлений

**Файлы:** `bot/keyboards/user.py`, `bot/handlers/user/profile.py`

**Примечание:** Для полного исправления уведомлений нужно проверить сервис scheduler и notification (не сделано в этой версии)

---

## Инструкции по применению изменений

### 1. Применить миграцию БД

```bash
# На сервере
cd ~/DeployGram-Bot
alembic upgrade head
```

### 2. Перезапустить бота

```bash
cd ~/DeployGram-Bot/docker
docker compose -p mainbot restart bot
```

### 3. Проверить логи

```bash
docker compose -p mainbot logs -f bot
```
